功能与数据说明

本版使用浏览器内的确定性关键词解析器，而不是大语言模型；主观词语的数值阈值仅是演示默认值，可手动调整。未识别语句会明确提示，不会被静默当作有效条件。

指标包括营收同比、净利润同比、ROE、毛利率、PE、PB、资产负债率、60 日年化波动率、近一年最大回撤。数值全部虚构，指标说明只用于演示筛选逻辑。真实金融数据、回测和持续监控不在此静态版范围内。
