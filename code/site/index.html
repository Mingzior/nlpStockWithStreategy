功能与数据说明

第一阶段：浏览器内使用确定性关键词解析器（非 LLM），主观阈值仅为可编辑建议。真实数据由 GitHub Actions 定期获取扶摇 REST API 生成静态快照，网页不接触 API Key。

指标包括营收同比、净利润同比、ROE、毛利率、PE、PB、资产负债率、60 日年化波动率、近一年最大回撤。真实快照当前仅映射已验证的 PE(TTM)、PB(MRQ) 字段，其余指标明确为缺失；股票范围仅限预设代码，不代表全市场。未配置密钥或验证失败时不显示虚构数据。实时 LLM、回测和持续监控不在第一阶段范围内。
