## 已实现

## 关键架构边界
- AI/语义层：当前 MVP 使用**确定性关键词解析**，不是 LLM。iFinD `search_securities` 提供外部自然语言智能筛选，但其内部模型/规则不可验证，结果保持原文。
- 确定性规则引擎：仅针对具有明确单位、时间和来源的结构化指标计算 pass/fail/missing。
- 数据工具：扶摇和 iFinD 的真实数据由服务端读取，不在浏览器暴露密钥。
- **重要未完成**：iFinD `tools/call` 的成功响应样例及字段映射；真实股票的逐规则入选/排除证据；线上服务端部署与端到端验收。不能把这些标记为完成。

## 测试矩阵
| 场景 | 期望 |
|---|---|
| ROE>=15，PE<30 | 可编辑结构化规则，运行演示引擎 |
| PE>30，PE<10 | 冲突检测阻止执行 |
| 模糊表达「好公司」 | 明确需澄清，不猜测 |
| 数据字段为 null | 未知而非入选 |
| 修改阈值重跑 | 显示前后差异 |
| 数据源切换 | 清空旧结果，避免跨源混用 |
| iFinD 未设置密钥 | 503 明确报错，不生成假数据 |
| iFinD MCP 超时/错误 | 502，不伪造结果 |
| 真实筛选响应 | 仅原样展示、标明来源/请求时点，不暗示已独立复核 |
| 用户输入「稳赚」「明天必涨」 | 不输出收益承诺或买卖指令 |

## AI 使用与修正记录
- AI Coding 生成初版 React/TanStack Start 页面、规则引擎、PRD、测试及数据适配器。
- 人工/工具验证发现：初版全局文案将合成数据误称为所有结果；已改为明确分区。
- 发现切换数据源后可能保留旧筛选结果；已增加清空机制。
- 发现 Lovable 源码同步缺少根路由引用的错误报告模块；已补齐。
- 发现 iFinD 只有工具发现、没有真实业务调用；新增服务端受限 `tools/call` 路由和 UI。
- 未声称 LLM 解析、真实数据逐规则判定或生产部署已完成。

## 安全与部署
- Secrets：`IFIND_MCP_AUTHORIZATION`、`FUYAO_API_KEY`，只能放在服务器环境，不允许以 `VITE_` 前缀暴露。
- GitHub Actions Secrets **不会自动注入**线上服务器；部署平台需要单独配置。
- 禁止输出确定性涨跌预测、收益承诺或直接买卖建议。
- 不应公开上传受限数据或完整上游响应日志；演示可展示经核准的数据字段。
- 当前 MCP `/api/screen` 为公网请求接口；正式开放前需要身份验证、速率限制和配额控制，防止滥用账户额度。
